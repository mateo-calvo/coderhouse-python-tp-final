Sobre este proyecto

¡Hola! Mi nombre es Mateo Calvo y este blog representa el Trabajo Práctico Final del curso de Python en Coderhouse.

El objetivo de esta entrega es consolidar e integrar todas las herramientas y metodologías vistas a lo largo de la cursada: desde la estructuración de modelos en una base de datos relacional con Django ORM, hasta el control de accesos mediante vistas basadas en clases protegidas, carga y tratamiento de archivos estáticos y media, y un diseño responsive moderno con Bootstrap 5.

Principales funcionalidades desarrolladas:
  • CRUD completo de publicaciones: Crear, listar, leer en detalle, editar y eliminar artículos con soporte para imágenes.
  • Carga y visualización de imágenes segura: Si un artículo carece de imagen, la interfaz no se rompe y utiliza imágenes alternativas inteligentes.
  • Motor de búsqueda integrado: Permite filtrar publicaciones por título, subtítulo o cuerpo de texto, mostrando avisos informativos.
  • Gestión de usuarios y perfiles: Registro, login, logout, avatar personalizado, biografía y enlace web.
  • Rutas protegidas por permisos: Solo usuarios autenticados pueden crear artículos o editar sus perfiles; y solo los autores o superusuarios pueden modificar/eliminar sus propios posts.
Stack Tecnológico
  • Python 3.14.x / 3.x
  • Django 6.1.x
  • Bootstrap 5.3.3
  • Pillow 13.0.x
  • Base de datos SQLite
